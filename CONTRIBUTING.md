# Contributing

## Workflow

- Open an issue first for substantial changes.
- Create a topic branch from `main`.
- Do not push directly to `main`.
- Open a pull request for all changes.

## Local Setup

```bash
npm ci
npm test
```

## Pull Request Expectations

- Keep changes scoped and reviewable.
- Update documentation when behavior or usage changes.
- Keep workflows and token permissions minimal.
- Wait for CI to pass before merge.

## Security

For vulnerabilities, follow [SECURITY.md](SECURITY.md) and avoid public
disclosure.
